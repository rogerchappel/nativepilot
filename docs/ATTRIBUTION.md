# Attribution

NativePilot was selected from an OSS Factory idea PRD that cited demand for AI-ready React Native boilerplates.

The key public inspiration was `kuraydev/react-native-typescript-boilerplate`, observed on 2026-05-15 with strong GitHub template demand and AI-ready positioning. NativePilot does not copy that implementation, screens, assets, or naming. The differentiator is an original generator + doctor + agent handoff workflow for Expo-first apps.
